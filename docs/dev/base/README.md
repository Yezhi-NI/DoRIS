# DoRIS — расширение 1С: разработчику

Снимок исходников 04.11.2026; серверный сервис 0.2 beta, Mobile 0.0.2 beta, протокол 2. Описание по коду, без запуска 1С, Flutter-приложения и OCR.

[README](README.md) · [Архитектура](ARCHITECTURE.md) · [Модули](MODULES.md) · [Цепочки](PIPELINES.md) · [Данные](DATA_AND_PROTOCOLS.md)

Читайте ARCHITECTURE для границ компонентов, MODULES для каждого исходного модуля и сигнатур, PIPELINES для последовательностей и ошибок, DATA_AND_PROTOCOLS для схем и контрактов. Пользовательские действия описаны отдельно в [руководстве](../../user/DoRIS_Руководство_пользователя.md).

Целевая проверяемая среда — 1С 8.3.27 и Android 11+ (minSdk 30). Публичный протокол 2 не равен историческому сегменту /v1/ в URL. Файловый пакет v2 и QR настроек v3 — разные форматы. Документы этой папки описывают текущий код, а не гарантию исполнения в любой конфигурации.

Не храните реальные токены, ключи подписи и содержимое документов в примерах. Токены HTTP и файлового обмена различны. Успех загрузки/выгрузки не равен OCR или проведённому поступлению.

В Configuration.xml остаётся Version=0.1 beta; /info возвращает 0.2 beta. LocalPaddleOCR уже зарегистрирован вручную, в отличие от ранних отчётов. Сервис сохраняет Document при явном втором аргументе; мобильное заполнение разделено на OCR и транзакционную запись.
